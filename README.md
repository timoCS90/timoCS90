### Hi there, I'm Timo 👋

My journey into the world of programming started in a bootcamp, but my real passion came from combining what I love most: **music and technology**. As a synth enthusiast who wanted to build my own instruments, I started exploring **microcontrollers** and **software synthesizer development**. This led to a key realization about the importance of low **latency**, which is why I've been focused on **performance-oriented programming with C++**.

On my journey, I created a program to convert MIDI signals from microcontrollers into computer commands like play, pause, and new tab. I also recently built a full-stack website for a friend's company, showcasing my ability to tackle real-world projects.
